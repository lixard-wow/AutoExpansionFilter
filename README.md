# Auto Expansion Filter

Stop wading through old-expansion items. Auto Expansion Filter turns on "Current Expansion Only" for you every time you open the Auction House or the Crafting Orders browser.

- **Download:** [CurseForge](https://www.curseforge.com/wow/addons/auto-expansion-filter)
- **User guide:** [lixard-wow.github.io/auto-expansion-filter](https://lixard-wow.github.io/auto-expansion-filter/)
- **Game:** Retail, Midnight
- **Setup:** none needed

## What it does
- **Auction House:** turns on "Current Expansion Only" every time the search bar appears.
- **Crafting Orders:** turns on the same filter when you browse customer orders.
- Each one has its own on/off switch.
- Checks a few times as the window opens, because the game doesn't always accept the change on the first try.

It doesn't change any other window or filter. Settings apply to every character on your account.

## Commands
| Command | What it does |
| --- | --- |
| `/aef` | Open the settings window |
| `/aef on` | Turn on both filters |
| `/aef off` | Turn off both filters |
| `/aef help` | List the commands in chat |

`/autofilter` and `/expfilter` work the same as `/aef`.
